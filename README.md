# Oylanayiq — Интерактивті логикалық дамыту платформасы

**Oylanayiq** — балалар мен жастардың логикалық ойлауын, есте сақтау қабілетін және зияткерлік әлеуетін арттыруға арналған заманауи білім беру платформасы. Жоба қазақ мәдениеті мен құндылықтарын заманауи технологиялармен ұштастыра отырып, 12 түрлі интеллектуалды ойынды ұсынады.

## 🚀 Негізгі артықшылықтары

- **Ұлттық колорит**: Ойындардың мазмұны Қазақстан тарихы, географиясы мен салт-дәстүріне негізделген.
- **Кешенді даму**: Платформа алгоритмдік ойлауды, математикалық логиканы және криптография негіздерін үйретеді.
- **Геймификация**: Пайдаланушылар монета жинап, дүкеннен нақты және виртуалды марапаттар ала алады.
- **SMS Авторизация**: Қауіпсіз және заманауи кіру жүйесі (симуляцияланған).

## 🛠 Технологиялық стек

- **Backend**: Node.js, Express.js
- **Деректер базасы**: SQLite (better-sqlite3)
- **Frontend**: Vanilla JavaScript, CSS3, HTML5 (SPA элементтерімен)
- **Сессиялар**: express-session, connect-sqlite3

## 📦 Жобаны іске қосу

### Быстрый старт (PowerShell)

```powershell
Remove-Item -Recurse -Force node_modules -ErrorAction SilentlyContinue
Remove-Item -Force package-lock.json -ErrorAction SilentlyContinue

npm cache verify
npm install

npm audit
npm run dev
```

1. **Тәуелділіктерді орнату**:
   ```bash

   ```

2. **Серверді іске қосу**:

